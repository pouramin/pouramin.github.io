Where Did the Idea Come From?

The question behind JEV

❔

The Core Question

Why ask a large LLM to generate paragraphs when software often needs only a decision?

🧠

System 1 Inspiration

JEV follows fast, intuitive decision-making — inspired by Daniel Kahneman, System 1 vs. System 2.

📈

Why the name JEV?

Named after William Stanley Jevons and the Jevons paradox: when efficiency improves, total usage can grow.

Built by TypeSafe as a “System One” decision model for automation.

Why Teams Use JEV

Faster decisions, lower cost, better automation

⚡

Lower latency

A fast decision layer can be quicker than asking a large model to reason in text.

🪙

Lower cost

Use expensive models only when the task truly needs them.

🔀

Better routing

Simple tasks go to lighter models; hard tasks go to stronger ones.

🛡️

Calibrated confidence

JEV returns probabilities, not just guesses.

TypeSafe says JEV is trained for calibrated decisions using RLCD.
