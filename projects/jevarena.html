JEVArena

A visual decision-routing simulator for seeing how a routing layer can classify a task, choose a model tier, and trade cost/runtime against direct fixed-model execution.

Why it exists

Routing is hard to explain with a single cost number. JEVArena turns the decision path into something visible: prompt difficulty, selected tier, decision time, route distribution, token/cost assumptions and comparison against a direct model.

It is deliberately a simulator, not a claim of live provider measurements.

Current simulator model

01
Single + benchmark runs

Run one prompt or randomized benchmark suites from a 1,500-prompt pool.

02
Decision routing view

See route target, decision timing, total decision cost and live route distribution separately from final model execution.

03
Capability mismatch

If a lightweight fixed model is asked to handle a harder task, the simulator increases effective tokens and runtime to represent extra loops, retries and repeated context processing.

04
No API dependency

The normal web simulator runs without an account or API key, and a portable Windows package is available for offline-style local use.
