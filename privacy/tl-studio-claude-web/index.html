PRIVACY

TL Studio Claude Web Bridge

Privacy policy · Effective October 3, 2026

TL Studio Claude Web Bridge is a Chrome extension that connects the TL Studio desktop/local application to a Claude Web session already signed in to the same Chrome profile. The extension is an inference transport only; TL Studio retains control of its Agent loop, tools, permissions, files, terminal, sessions, and persistence.

Data the extension handles

When you use the Claude Web provider in TL Studio, the extension temporarily handles the prompt content that TL Studio asks it to send to Claude Web and the response content returned by Claude Web. This processing is necessary to provide the feature you explicitly request.

The extension does not use this content for advertising, profiling, analytics, or unrelated purposes.

Authentication and browser credentials

The extension does not read, export, copy, serialize, or store your Claude cookies, sessionKey, passwords, or other browser authentication credentials. Authenticated Claude requests run in the page context of claude.ai, and Chrome keeps the signed-in session browser-owned.

Storage and retention

The extension does not maintain its own database and does not persist Claude prompts, Claude responses, cookies, session keys, or account credentials. TL Studio may store your local project/session history on your own machine according to TL Studio's local application behavior.

Data sharing

Prompt content is sent to Claude Web at claude.ai only when you select and use the Claude Web provider. Claude's handling of data is governed by Anthropic's own terms and privacy practices. The extension does not sell user data and does not share user data with advertisers or data brokers.

Permissions

The extension requests access to https://claude.ai/* and the Chrome scripting capability required to run the authenticated request in the Claude page context. It accepts bridge connections only from local TL Studio pages on localhost or 127.0.0.1.

The extension does not request Chrome cookie access, debugger access, browsing-history access, clipboard access, or broad access to unrelated websites.

Security

The bridge accepts only the limited transport operations needed to probe the Claude Web session and complete model requests. The extension has no direct authority over TL Studio project files, terminal commands, permission decisions, sessions, plugins, or tool execution.

Changes to this policy

If the extension's data handling changes materially, this policy will be updated before the changed behavior is published.
