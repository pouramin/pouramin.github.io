# pouramin.dev

Personal builder hub for Amin Pour.

## Included
- Responsive multi-page static site
- Projects + case studies
- Now / Lab / Builds / Videos / Build Log / Uses / About / Work With Me / Start Here
- Dark/light theme
- Command palette (`Ctrl/Cmd + K`)
- Terminal easter egg
- Progressive GitHub public activity feed
- GitHub Pages-ready metadata

## Preview locally
Use any static server from this directory. Example:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Domain
No `CNAME` is included yet. Add `CNAME` containing `pouramin.dev` only after the design is approved and GitHub Pages is enabled.
